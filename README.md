## What it is

**Atlas of Nations** — a national statistics site covering 40 countries with 12 World Bank indicators each: population, GDP, GDP per capita (nominal and PPP), life expectancy, land area, CO2 per capita, share aged 65+, internet users, fertility rate, under-5 mortality, and urban population. Every figure shows the year it was published for (mostly 2024).

- **Home**: world totals, top-10 charts (population, GDP, life expectancy) as inline SVG, featured countries.
- **Rankings**: all 40 countries on six headline measures, with tabs and click-to-sort tables.
- **Countries**: a searchable, filterable directory of all 40 countries.
- **Country pages**: one detail page per country — headline stats vs the 40-country median, the full indicator table with ranks, and links to the most similar economies.
- **Compare**: pick up to three countries for a side-by-side table (best value highlighted) and a population chart; picks live in the URL, so a comparison can be shared as a link.
- **Sources & methods**: the indicator list with World Bank series codes, and how figures were chosen.

The site is plain static files: no build step, no tracking, no cookies, no network requests — every page works offline, on desktop and on a phone.

## Data source

World Bank Open Data, World Development Indicators, fetched from the public API (`api.worldbank.org/v2`, no key needed) and embedded in `data/countries.json` (40 countries × 12 indicators, 479 of 480 values from 2024; Myanmar's internet-users figure is 2020, the latest the Bank holds). See `methodology.html` in the generated site for the full series list.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
# open http://localhost:8080
```

`main.ts` (Node 22, standard library only) generates the whole static site from `data/countries.json` into `out/app/`, copies `screenshots/`, and writes `out/dossier.json`. Run it twice and the output is byte-identical.

## Layout

- `main.ts` — the generator: reads `data/countries.json`, renders every page, writes the dossier.
- `data/countries.json` — the embedded World Bank dataset.
- `templates/style.css` — the site's stylesheet; `templates/app.js` — search, sorting, tabs, compare picker.
- `app/` is generated by `main.ts` (it is not stored in the repo).
- `screenshots/` — 4 real renders of the site (see `shots.json` for the views).
- `vendor/makefun-frontend.ts` — the kit's dossier library, unchanged.
- `serve.ts` — tiny static server for local testing.
